## ✨ Features
- 📷 **Profile Photo Upload**: Real-time image upload with automatic aspect fitting inside the retro polaroid badge.
- 🎨 **Dynamic Profile Customizer**: Live real-time updates for Name, Role/Stack, Builder ID, Location, and Random Builder Titles (`Terminal Wizard`, `Code Alchemist`, `Deploy Captain`, etc.).
- 🛵 **Sticker Pack & Badges**: Tropical Hacker House Goa stickers (palm trees, coconut, sunset, scooter, waves).
- 🏷️ **Dynamic Barcode Generator**: Algorithmic barcode rendered with dynamic builder ID serial numbers.
- 📥 **High-Resolution Export**: 3x retina canvas rendering to download your ID as a crisp PNG.
- 🐦 **Share on X (#FrameInGoa)**: 1-click instant sharing to Twitter/X with prefilled event hashtags.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Vanilla CSS with retro typography: *Anton*, *JetBrains Mono*, *Noto Sans Devanagari*, *Inter*)
- **Vanilla JavaScript** (ES6+)
- **html2canvas** for high-res PNG badge generation
- **Vercel** for continuous deployment
